## Actualizar el contenido

1. Editar `CV-Yordani-Majuan-Suarez.md` (fuente de verdad del contenido del CV).
2. Reflejar los mismos cambios en `index.html` donde aplique (proyectos, experiencia, habilidades, contacto).
3. Regenerar el PDF con el script generador (ReportLab) a partir del contenido actualizado.
4. Commit y push a `main` — GitHub Pages se actualiza automáticamente en 1-2 minutos.
